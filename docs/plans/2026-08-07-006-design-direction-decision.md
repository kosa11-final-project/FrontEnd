# 디자인 방향 확정: Mesh Forecast + Olive Green

## 결정

통합 재고 관제 플랫폼의 기본 디자인 방향을 다음 조합으로 확정한다.

- 스타일: `Mesh Forecast`
- 메인 컬러: `Olive Green`
- 기본 진입 상태: `/inventory` 앱 셸에서 위 조합을 전역 토큰으로 사용

## 적용 원칙

- 그라디언트 메시는 배경과 요약 표면에 제한적으로 사용한다.
- 데이터 테이블은 불투명한 표면과 충분한 대비를 유지한다.
- 주색 `#636B2F`는 주요 행동, 선택 상태, 포커스에 사용한다.
- 밝은 배경은 `#F4F6EB`, 보조 표면은 `#EEF1DF`를 사용한다.
- 강조 면은 `#D4DE95`, 깊은 텍스트·내비게이션은 `#3D4127`을 사용한다.
- 위험·주의·양호는 올리브 색상으로 대체하지 않고 의미 기반 상태색을 별도로 유지한다.
- 위험등급은 색상만으로 전달하지 않고 텍스트와 아이콘을 함께 사용한다.
- ZONE과 KAN은 계속 화면에 표시하지 않는다.

## 운영 화면 적합성

Mesh Forecast는 수요 예측과 재고 흐름을 시각적으로 강조하기 좋고, Olive Green은 식품·자연·운영 도메인과 연결되는 브랜드 톤을 제공합니다. 다만 관제 테이블에서는 색면보다 숫자 비교가 우선이므로 그라디언트의 채도와 투명도를 낮추고, 행·열 구분선과 포커스 상태를 선명하게 유지합니다.

## 후속 작업

1. `src/styles.css`의 공통 semantic token을 Olive Green 기준으로 확정한다.
2. 사이드바 기준 기본 라우트와 앱 셸을 팀 공통 구조로 유지한다.
3. 세션 쿠키·CSRF·401·403 처리의 프론트엔드 경계를 문서화한다.
4. Sentry 초기화와 환경변수 구조를 추가한다.
5. 실제 기능이 시작될 때 `entities/inventory`와 `features/inventory-filter`를 첫 FSD slice로 만든다.
6. Figma의 `Dashboard Filter · Foundations` 변수와 코드 토큰 이름을 대조해 색상 값을 동기화한다.

## 비교용 스킨

비교용 스킨과 10개 디자인 갤러리는 최종 방향 확정에 따라 운영 코드에서 제거한다. Mesh Forecast와 Olive Green만 공통 토큰과 앱 셸의 기본값으로 유지한다.
